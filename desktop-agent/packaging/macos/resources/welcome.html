DeskSync for Mac

Control this Mac from your phone: see its screen, type, and click, from anywhere.

This installer will:

  • Install DeskSync.app into your Applications folder
  • Add the desksync command for setup and diagnostics

Afterwards you'll run a short guided setup to sign in and grant the screen and input permissions macOS requires.

DeskSync only streams your screen while you have an active session. Nothing is recorded, and the connection is peer-to-peer.
